W05 Project Site Plan: ZeroDataComm

This plan outlines the design and content strategy for ZeroDataComm, a promotional website for a zero-data communication platform.

1. Site Name and Branding

Site Name: ZeroDataComm

ZeroDataComm ™

Reason for Name: The name is highly descriptive, clearly communicating the primary value proposition: communication ("Comm") that uses zero cellular data ("ZeroData"). It is short, modern, and suitable for a tech startup.

Optional Domain: zerodatacom.app

2. Site Purpose

The main goal of the site is to serve as the primary marketing and informational resource for the ZeroDataComm application. Key information and services provided:

  • **Value Proposition:** Clearly explain *how* the app works without data and emphasize cost savings.
  • **Feature Showcase:** Detail the app's main functionalities (secure messaging, community forums).
  • **Dynamic Pricing Tool:** Provide a dynamic calculator allowing users to determine the annual subscription cost based on their needs. (The basic JavaScript requirement.)
  • **Access/Download:** Direct users to purchase an access code or download the mobile application.

3. Scenarios (Target Audience Questions)

The target audience includes individuals in emerging markets (like the DRC), students, and budget-conscious families.

  1. "How much will a year-long family plan cost me, and how do I calculate the total price?" (Addresses budget-conscious users seeking the dynamic calculator feature.)
  2. "Is this app secure, and can I use it for more than just text messages?" (Addresses users concerned about privacy and the full feature set.)

4. Color Scheme

The scheme uses reliable, cool colors, typical of tech and financial services, ensuring excellent contrast and a modern, clean look. (Used throughout this document)

  • Accent Color (Electric Blue - #3498DB)

    Used for: **Call-to-Action (CTA) buttons**, key interactive elements, links, and borders to draw attention. Represents innovation and trust.

  • Secondary/Text Color (Dark Charcoal Blue - #2C3E50)

    Used for: **All headings (H1, H2)** and main body text. Provides high contrast against the light background.

  • Primary Background (Light Cool Gray - #F0F4F8)

    Used for: **General page background** to give a soft, technological feel without being stark white.

  • Sub-Accent Color (Pure White - #FFFFFF)

    Used for: **Backgrounds of main content cards** (like this container) and areas displaying important data (e.g., Pricing Calculator result).

5. Typography

A sans-serif combination is chosen for maximum readability and a professional, contemporary look, consistent with a technology product.

  • Montserrat (Sans-serif): Used for **Headings (H1, H2, H3)**. This font is geometric and bold, perfect for modern branding and making main points stand out.
    Example of Montserrat (Heading Font)
  • Open Sans (Sans-serif): Used for **Body Text, Paragraphs, and Navigation**. A highly readable and versatile font, optimized for web display.
    Example of Open Sans (Body Text)
